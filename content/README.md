## 🛠️ Do a Project

Inspired to make something? Here’s a path to get you started.

1.  **Learn the Process**: Make sure you've reviewed the **[[atlas/concepts/Design Thinking MOC|Design Thinking MOC]]**.
2.  **Build Foundational Skills**:
    -   **Prerequisite Concept**: [[atlas/concepts/Constraint-Based Creativity|Constraint-Based Creativity]].
    -   **Prerequisite Tool**: [[atlas/tools-techniques/Laser Cutting|Laser Cutting]].
    -   **Starter Project**: Try the **[[efforts/Family Coasters|Family Coasters]]** project. It's designed to be the perfect introduction.
3.  **Tackle a Real Problem**:
    -   **Prerequisite Concepts**: [[atlas/concepts/User Feedback|User Feedback]], [[atlas/concepts/4Ms Framework MOC|4Ms Framework]].
    -   **Prerequisite Tool**: [[atlas/tools-techniques/Onshape CAD|Onshape CAD]].
    -   **Next-Level Project**: Review the **[[efforts/Robot Storage|Robot Storage]]** project to see how to solve a problem for a real "client."
