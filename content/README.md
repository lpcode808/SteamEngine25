# STEAM Course Learning Portal

> **Bringing Ideas to Life: A Journey Through STEAM Education**

This repository contains the educational content for a semester-long STEAM (Science, Technology, Engineering, Art, Mathematics) course at Hawaiʻi School for Girls at La Pietra. It documents the complete learning journey of students as they developed skills in design thinking, AI partnership, laser cutting, CAD design, and collaborative problem-solving.

## 🎯 What You'll Find Here

### **Learning Journey Documentation** 📚
- **35 days of detailed learning progression** from basic tool safety to professional collaboration
- **Real project case studies** including robot storage solutions and cross-curricular educational tools
- **Milestone achievements** and breakthrough moments in student development
- **Reflection methods** and portfolio development practices

### **Framework Integration** 🧠
- **Design Thinking Process**: Empathize → Define → Ideate → Prototype → Test applications
- **4 Ms Framework**: Maker, Machine, Method, Materials, Margin systems thinking
- **AI as Creative Partner**: Ethics-first approach to responsible AI integration
- **Cross-Curricular Connections**: STEAM skills supporting physics, Spanish, mathematics, and more

### **Technical Skills Development** ⚙️
- **Laser Cutting Mastery**: From safety fundamentals to precision fabrication
- **Onshape CAD**: Parametric design thinking and professional workflows
- **AI Tool Integration**: Magic School, Gemini, and responsible generative AI use
- **Assessment Portfolio**: Growth-focused evaluation and reflection practices

## 🔧 Technical Setup

### **Quartz Deployment (Recommended)**
This site is optimized for [Quartz](https://quartz.jzhao.xyz/), a fast static site generator designed for educational content:

1. Install Quartz following the [official setup guide](https://quartz.jzhao.xyz/setup/)
2. Clone this repository
3. Run `npx quartz build --serve` for local development
4. Deploy to your hosting platform of choice

### **GitHub Pages Fallback**
If Quartz isn't available, the site includes Jekyll configuration for GitHub Pages compatibility:

1. Enable GitHub Pages in repository settings
2. Select "Deploy from branch" and choose your main branch
3. The site will build automatically using the included `_config.yml`

### **Local Development**
For simple local viewing without build tools:

1. Clone the repository
2. Open `index.md` in your preferred markdown viewer
3. Follow links to explore content structure
